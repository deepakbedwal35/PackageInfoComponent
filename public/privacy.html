1. Overview

2. Data Collection and Processing

This component does not collect, record, track, or persist any personal data or search queries. All query parsing and state routing take place strictly inside your browser runtime.

3. External Public API Requests

To provide package metadata, metrics, and bundle sizes, the component sends read-only HTTPS GET requests to the following public developer services:

  • Official npm Registry (registry.npmjs.org) and mirrors (registry.npmmirror.com) for public package manifests.
  • npm Download Counts API (api.npmjs.org) for aggregated public download statistics.
  • Bundlephobia API (bundlephobia.com) for public minified and gzipped package asset sizes.

These requests do not convey user identifiers, cookies, or account tokens.
